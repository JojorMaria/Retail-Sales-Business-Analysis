# Retail Sales Business Analysis

An end-to-end data analysis project using Python, SQL, and Power BI to explore retail sales performance, profitability, customer segments, and regional business trends.

## Project Overview
This project analyzes the Sample Superstore dataset to identify business performance patterns and generate actionable insights.
The analysis focuses on evaluating sales and profitability across product categories, customer segments, and geographical regions.
The project uses Python for data exploration and preparation, SQL for business analysis and data validation, and Power BI to create an interactive dashboard.

## Business Objectives
- Analyze overall sales and profit performance.
- Identify the most and least profitable product categories.
- Evaluate customer segment performance.
- Compare business performance across regions.
- Develop an interactive dashboard to support data-driven decision-making.

## Tools & Technologies
- **Python:** Data exploration and preparation.
- **Pandas:** Data manipulation and analysis.
- **SQL:** Data validation and business analysis.
- **TiDB Cloud:** Cloud database.
- **Power BI:** Interactive dashboard and visualization.
- **Jupyter Notebook:** Python analysis environment.
